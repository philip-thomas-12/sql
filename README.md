# 📁 SQL Practice Files

Welcome to the **SQL Practice Folder**. This repository contains a variety of SQL scripts that demonstrate essential concepts in database design, querying, and management using MySQL syntax. These files are useful for practice, reference, and showcasing fundamental to intermediate-level SQL skills.

---

## 📄 File Descriptions

| File Name                    | Description |
|-----------------------------|-------------|
| `create_tables.sql`         | Creates the `Company` database with `Employees` and `Departments` tables using primary and foreign keys. |
| `insert_data.sql`           | Inserts sample data into `Employees` and `Departments` tables. |
| `select_queries.sql`        | Demonstrates basic `SELECT` statements and `JOIN` operations. |
| `aggregate_functions.sql`   | Shows use of `AVG()`, `SUM()`, and `GROUP BY` for analyzing salary data. |
| `views_and_procedures.sql`  | Creates a view for high earners and a stored procedure to give a raise. |
| `advanced_queries.sql`      | Contains subqueries and CTE (Common Table Expression) examples. |
| `constraints_demo.sql`      | Demonstrates constraints such as `PRIMARY KEY`, `UNIQUE`, and `CHECK`. |
| `normalization_example.sql` | Shows the process of normalizing a denormalized order table into 3NF. |
| `triggers_demo.sql`         | Example of a trigger to log salary changes in an audit table. |
| `indexes_demo.sql`          | Adds indexes to improve performance on query-heavy columns. |
| `subqueries_and_nested.sql` | More advanced subquery examples, including nested queries. |
| `transaction_demo.sql`      | Shows how to use transactions with `COMMIT` and `ROLLBACK`. |
| `backup_restore.sql`        | Instructions and examples for exporting and restoring databases. |
| `json_handling.sql`         | Demonstrates using `JSON` data types and functions in MySQL. |
